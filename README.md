# GeoWorks releases

Update feed for the GeoWorks desktop app (SOM Survey Instruments).

* `geoworks_update.json` - the manifest the app checks once a day at start-up.
* Builds are attached to the GitHub releases on the right; the manifest's `url` points at the current one.

Latest: see the manifest. Installed copies of 0.4.0 and later update themselves from Help > Check for updates.
First-time install: download the zip from the latest release, unzip anywhere, run `GeoWorks.exe`.
